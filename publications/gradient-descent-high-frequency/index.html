Gradient Descent Fails to Learn High-frequency Functions and Modular Arithmetic

Rustem Takhanov, Maxat Tezekbayev, Artur Pak, Arman Bolatov, Zhenisbek Assylbekov

Paper PDFarXivMachine Learning (MLJ)

About this paper

Analyzes why gradient-based methods struggle with high-frequency periodic functions and modular multiplication.

For these target classes, the gradient can carry very little information about the function being learned. The analysis relates this difficulty to gradient variance and the approximate orthogonality of candidate target functions.
